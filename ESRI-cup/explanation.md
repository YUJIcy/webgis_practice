Project文件夹中为ArcGIS Pro图层文件,包括所需的四种shp（武汉市区划、医院点、带权重路网、拥堵指数）和Services数据库（含网络分析要素集）  
#### GeoScene文件夹中为项目文件：
- css：样式文件
- fonts：图标文件（不用管）
- images：图片文件
- scripts：javascript代码（简单分成了三个，main.js是涉及地图服务和处理的主要文件）
- main.html：核心html文件，是网页的页面设计部分，连接了css样式和js代码  

---

The Project folder contains ArcGIS Pro layer files, including the four required SHP files (Wuhan urban administrative divisions, hospital point data, weighted road network, congestion index) and the Services database (which contains network analysis feature datasets).  
#### The GeoScene folder stores project files with the following subfolders:
- css: Stylesheet files
- fonts: Icon files (can be ignored)
- images: Image files
- scripts: JavaScript codes (split into three simple files; main.js is the primary file responsible for map services and data processing)
- main.html: The core HTML file that defines the webpage layout and links CSS stylesheets with JavaScript codes.
